# 練習注音 — เว็บฝึกอ่านและฝึกพิมพ์จู้อิน (Zhuyin / Bopomofo)

เว็บแอปหน้าเดียว (single-file HTML) สำหรับฝึกอ่านและฝึกพิมพ์จู้อิน (注音符號 / Bopomofo) ที่ใช้แทนกันในการสะกดเสียงภาษาจีนกลางในไต้หวัน ไม่ต้องติดตั้งอะไร เปิดไฟล์ `.html` ด้วยเบราว์เซอร์ก็ใช้งานได้ทันที ไม่มีการเชื่อมต่อเซิร์ฟเวอร์ ข้อมูลทั้งหมดอยู่ในเครื่องของผู้ใช้เท่านั้น

---

## โหมดการฝึกทั้ง 3 โหมด

### 1. โหมดฝึกอ่าน (閱讀)
แสดงตัวอักษร/คำในกรอบ **田字格** (กรอบสี่ช่องแบบสมุดฝึกเขียนตัวจีน) ทีละคำ กดปุ่ม **"เผยจู้อิน"** เพื่อดูคำอ่าน แล้วกด **"รู้แล้ว ✓"** หรือ **"ยังไม่รู้ ✗"** เพื่อสุ่มคำถัดไป เหมาะสำหรับทบทวนคำศัพท์แบบ flashcard

### 2. โหมดฝึกพิมพ์ (打字)
แสดงตัวอักษรทีละตัว ให้พิมพ์จู้อินของตัวอักษรนั้นด้วยคีย์บอร์ดจริง มีภาพ **แป้นพิมพ์เสมือน** ไฮไลต์ปุ่มที่กดแบบเรียลไทม์ พิมพ์เสร็จกด `Space` หรือ `Enter` เพื่อตรวจคำตอบ

### 3. โหมดพิมพ์ยาว / คำคม (長文)
แสดงข้อความยาวทั้งประโยค/คำคม ให้พิมพ์ไล่ไปทีละตัวอักษรต่อเนื่องแบบ typing test — ตัวที่กำลังพิมพ์ถูกไฮไลต์ พิมพ์ถูกจะเปลี่ยนเป็นสีเขียว พิมพ์ผิดเป็นสีแดงขีดเส้นใต้ แล้วเลื่อนไปตัวถัดไปให้อัตโนมัติ (ไม่ต้องกดยืนยันทีละตัว) เครื่องหมายวรรคตอน (， 。 ！ ？ ฯลฯ) จะถูกข้ามให้เองโดยไม่ต้องพิมพ์ พร้อมสถิติเรียลไทม์: เวลา, จำนวนถูก/ผิด, % ความแม่นยำ และความเร็ว (ตัวอักษร/นาที) เลือกสลับได้หลายบทคำคมในคลังเดียวกัน

---

## การนำเข้าคำศัพท์ / ข้อความของตัวเอง

รองรับทั้ง **อัปโหลดไฟล์ `.txt` / `.csv`** และ **วางข้อความลงในกล่องข้อความโดยตรง** — ทั้งฝั่งคลังคำศัพท์ (สำหรับโหมดอ่าน/พิมพ์) และฝั่งคลังคำคม (สำหรับโหมดพิมพ์ยาว) ใช้รูปแบบเดียวกัน:

```
ตัวอักษร,จู้อิน
```

- คั่นระหว่างตัวอักษรกับจู้อินด้วย **จุลภาค (,)** หรือ **แท็บ**
- ถ้าเป็นคำ/ประโยคหลายพยางค์ ให้ **เว้นวรรค** คั่นจู้อินของแต่ละตัวอักษรตามลำดับ
- บรรทัดที่ขึ้นต้นด้วย `#` จะถูกข้ามไป (ใช้เขียนคอมเมนต์ได้)
- สำหรับคำคม/ข้อความยาว ใส่จู้อิน**เฉพาะตัวอักษรจีน** เท่านั้น — เครื่องหมายวรรคตอนจะถูกตรวจจับและข้ามให้อัตโนมัติ ไม่ต้องใส่จู้อินกำกับ

**ตัวอย่างคลังคำศัพท์:**
```
你好,ㄋㄧˇ ㄏㄠˇ
謝謝,ㄒㄧㄝˋ ㄒㄧㄝ˙
一,ㄧ
```

**ตัวอย่างคลังคำคม:**
```
千里之行，始於足下,ㄑㄧㄢ ㄌㄧˇ ㄓ ㄒㄧㄥˊ ㄕˇ ㄩˊ ㄗㄨˊ ㄒㄧㄚˋ
```

> ⚠️ ข้อจำกัด: เว็บนี้ไม่ได้แปลงตัวอักษรจีนเป็นจู้อินให้อัตโนมัติ (ต้องพึ่งพจนานุกรมขนาดใหญ่ที่ฝังในไฟล์เดียวไม่ไหว) ผู้ใช้ต้องเตรียมไฟล์ที่มีจู้อินกำกับมาด้วยเสมอ

## การพิมพ์จู้อิน — ผังแป้นพิมพ์มาตรฐาน (大千 / Standard)

การพิมพ์จู้อินในเว็บนี้อ้างอิง**ตำแหน่งปุ่มจริงบนคีย์บอร์ด** (ใช้ `event.code` ของเบราว์เซอร์) ไม่ใช่ตัวอักษรที่พิมพ์ออกมา ดังนั้นต่อให้เครื่องตั้งเป็นคีย์บอร์ดภาษาไทย อังกฤษ หรือภาษาอื่น ก็ยังพิมพ์จู้อินได้ปกติ โดยยึดผังมาตรฐานที่ใช้กันทั่วไปในไต้หวัน (ผัง 大千 / 標準) ดังนี้:

| แถวปุ่ม | การจับคู่ |
|---|---|
| ตัวเลข 1–0, - | `1`ㄅ `2`ㄉ `3`ˇ(วรรณยุกต์3) `4`ˋ(วรรณยุกต์4) `5`ㄓ `6`ˊ(วรรณยุกต์2) `7`˙(เสียงเบา) `8`ㄚ `9`ㄞ `0`ㄢ `-`ㄦ |
| Q–P | `Q`ㄆ `W`ㄊ `E`ㄍ `R`ㄐ `T`ㄔ `Y`ㄗ `U`ㄧ `I`ㄛ `O`ㄟ `P`ㄣ |
| A–L, ; | `A`ㄇ `S`ㄋ `D`ㄎ `F`ㄑ `G`ㄕ `H`ㄘ `J`ㄨ `K`ㄜ `L`ㄠ `;`ㄤ |
| Z–M, , . / | `Z`ㄈ `X`ㄌ `C`ㄏ `V`ㄒ `B`ㄖ `N`ㄙ `M`ㄩ `,`ㄝ `.`ㄡ `/`ㄥ |
| `Space` | ยืนยัน/ตรวจคำตอบ — ถ้าไม่ได้กดปุ่มวรรณยุกต์เลย ระบบจะถือว่าเป็น**วรรณยุกต์เสียงที่ 1** (ไม่มีเครื่องหมาย) |
| `Backspace` | ลบสัญลักษณ์ล่าสุดในช่องพิมพ์ |
| `Enter` | ตรวจคำตอบ (ทำงานเหมือน Space) |


## รายละเอียดทางเทคนิค

- ไฟล์เดียวจบ: HTML + CSS + JavaScript แบบ vanilla ไม่มี dependency ภายนอก (นอกจากฟอนต์ Google Fonts: Noto Serif TC, Noto Sans Thai)
- ทำงานฝั่ง client ล้วนๆ ไม่มีการส่งข้อมูลออกไปเซิร์ฟเวอร์ไหน
- คะแนน/สถิติเก็บเฉพาะระหว่างเซสชันที่เปิดอยู่ (รีเฟรชหน้าแล้วจะรีเซ็ต) — ยังไม่มีการบันทึกถาวรข้ามครั้งการใช้งาน
- รองรับเบราว์เซอร์สมัยใหม่ทั่วไป (Chrome, Edge, Firefox, Safari)

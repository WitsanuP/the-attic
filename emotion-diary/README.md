# สมุดบันทึกอารมณ์ (Wheel of Emotions Diary)

แอปบันทึกไดอารี่/ความรู้สึกแบบ local รันด้วย Python ล้วนๆ ไม่ต้องติดตั้งไลบรารีเพิ่ม
ข้อมูลทุกรายการถูกบันทึกเป็นไฟล์ `.json` แยกไฟล์ในเครื่องของคุณเอง (ไม่มีการส่งข้อมูลออกอินเทอร์เน็ต)

## วิธีรันบน WSL

1. เปิด WSL terminal (Ubuntu หรือ distro ที่คุณใช้)
2. ตรวจสอบว่ามี Python 3 อยู่แล้ว (ปกติมีติดมากับ Ubuntu):
   ```bash
   python3 --version
   ```
   ถ้ายังไม่มี ให้ติดตั้งก่อน:
   ```bash
   sudo apt update && sudo apt install -y python3
   ```
3. เข้าไปที่โฟลเดอร์โปรเจกต์นี้ (แก้ path ให้ตรงกับที่คุณวางไฟล์ไว้ เช่นถ้าเซฟไว้ที่ Downloads บน Windows):
   ```bash
   cd /mnt/c/Users/<ชื่อผู้ใช้>/Downloads/emotion-diary
   ```
   หรือถ้าคัดลอกไฟล์มาไว้ในฝั่ง Linux ของ WSL เอง (แนะนำ เพราะเร็วกว่า):
   ```bash
   cd ~/emotion-diary
   ```
4. รันเซิร์ฟเวอร์:
   ```bash
   python3 server.py
   ```
   จะเห็นข้อความ `สมุดบันทึกอารมณ์ กำลังทำงานที่ http://localhost:8000`
5. เปิดเบราว์เซอร์ (บน Windows ปกติ) ไปที่:
   ```
   http://localhost:8000
   ```
   WSL2 ส่ง port ไปให้ Windows อัตโนมัติ เปิดจาก Chrome/Edge บน Windows ได้เลย
6. กด `Ctrl+C` ใน terminal เพื่อหยุดเซิร์ฟเวอร์เมื่อเลิกใช้

## โครงสร้างไฟล์

```
emotion-diary/
├── server.py           ← เซิร์ฟเวอร์ (รันไฟล์นี้)
├── static/
│   ├── index.html
│   ├── style.css
│   └── app.js
└── data/
    └── entries/         ← บันทึกแต่ละรายการถูกเก็บเป็นไฟล์ .json ที่นี่
```

แต่ละไฟล์บันทึกในโฟลเดอร์ `data/entries/` มีข้อมูล:
- `date`, `time`, `createdAt` — วันเวลาที่บันทึก
- `core` — อารมณ์หลัก (เช่น สุข, โกรธ, เสียใจ ...)
- `level2`, `level3` — อารมณ์ที่เจาะลึกขึ้น (อาจเป็น `null` ถ้ากด "ไม่แน่ใจ")
- `unsure`, `unsureAt` — บอกว่าผู้ใช้กด "ไม่แน่ใจ" ที่ขั้นไหน
- `text` — ข้อความบันทึกเพิ่มเติม

## วิธีใช้งานหน้าเว็บ

1. เลือกอารมณ์หยาบๆ ก่อน (7 อารมณ์หลัก): สุข, ประหลาดใจ, กลัว, โกรธ, รังเกียจ, เสียใจ, ทุกข์
2. ระบบจะให้เลือกอารมณ์ที่เจาะลึกขึ้นอีกชั้น และเจาะลึกได้อีกชั้นหนึ่ง
3. ถ้ารู้สึกแบบกว้างๆ แต่ไม่รู้จะเจาะจงยังไง กดปุ่ม **"🤔 ไม่แน่ใจ"** ที่ปรากฏในแต่ละขั้นได้ทันที ระบบจะบันทึกเท่าที่รู้และติดป้าย "ไม่แน่ใจ" ไว้
4. เขียนบันทึกเพิ่มเติมได้ (จะเว้นว่างไว้ก็ได้) แล้วกด **บันทึกลงไฟล์**
5. รายการที่บันทึกแล้วจะแสดงด้านล่าง ลบทิ้งได้ถ้าต้องการ

## ปรับแต่งเพิ่มเติม

- แก้ไขชุดคำอารมณ์ทั้ง 3 ชั้นได้ที่ตัวแปร `EMOTION_TREE` ในไฟล์ `static/app.js`
- เปลี่ยนพอร์ตได้ที่ตัวแปร `PORT` ในไฟล์ `server.py`
